# gym-management-app-demo

Web app for managing gym operations and memberships

## Overview

Crea un'applicazione web demo per la gestione di una palestra e dei suoi iscritti.

L'applicazione deve simulare le operazioni quotidiane di una palestra moderna, con un'interfaccia professionale e intuitiva.

Funzionalità principali:

Dashboard con statistiche in tempo reale:
Iscritti attivi
Nuove iscrizioni del mese
Corsi più frequentati
Entrate mensili simulate
Gestione iscritti:
Elenco completo degli iscritti
Ricerca e filtri avanzati
Scheda dettagliata dell'iscritto
Storico presenze
Stato dell'abbonamento
Gestione abbonamenti:
Mensile, trimestrale, annuale
Scadenze e rinnovi
Storico pagamenti simulato
Gestione corsi:
Calendario settimanale
Prenotazione corsi
Limite posti disponibili
Lista partecipanti
Area istruttori:
Gestione corsi assegnati
Registro presenze
Note sugli allievi
Sistema notifiche:
Abbonamenti in scadenza
Promemoria corsi prenotati
Comunicazioni della palestra

Design e UX:

Interfaccia moderna stile SaaS premium.
Dashboard con grafici interattivi.
Tema chiaro/scuro.
Responsive per desktop, tablet e smartphone.
Animazioni leggere e professionali.

Dati demo:

200 iscritti generati automaticamente.
15 istruttori.
20 corsi attivi.
Storico presenze e pagamenti simulato.

Tecnologia suggerita:

React + TypeScript
Tailwind CSS
Mock API locale con dati JSON
Grafici tramite Chart.js

Obiettivo della demo:

Mostrare una piattaforma gestionale completa, realistica e pronta per dimostrazioni commerciali, test funzionali e presentazioni a potenziali clienti.
